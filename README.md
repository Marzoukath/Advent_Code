# 🎄 Advent of Code - Solutions Python

Bienvenue dans ce repository ! Vous y découvrirez une sélection de mes solutions pour les compétitions **Advent of Code 2024 et 2025**, entièrement codées en Python.

>  **Note** : Ce repository contient les jours que j'ai réussi à résoudre, et non la totalité des défis.

##  Démarrage Rapide

### Installation
```bash
git clone <lien_du_repository>
cd Advent_Code
```

### Utilisation
Accédez au répertoire du jour souhaité et exécutez le script avec votre interpréteur Python :
```bash
python DayX/dayxx
```
